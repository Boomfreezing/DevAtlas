## 正确性与可信度证据

| 主题 | 阅读顺序与用途 |
|---|---|
| 智能问答检索 | [合成回归基线](./QA_EVALUATION.md) → [真实仓库初始对照](./QA_REAL_EVALUATION.md) → [固定题库离线复测](./QA_RECHECK.md)；区分回归题、真实源码题、检索指标与尚待授权的生成回答验收 |
| 耦合关系 | [静态绑定与风险证据](./COUPLING_EVIDENCE.md) → [真实源码定向抽查](./COUPLING_REAL_EVALUATION.md)；后者补充 CommonJS、原型赋值及有哈希约束的原文补读边界，不是完整调用图准确率 |
| 项目与会话状态 | [状态一致性](./STATE_CONSISTENCY.md)：请求取消、项目隔离、同步缓存、源码引用及问答会话回归 |
| 质量与版本口径 | [质量页面验收](./QUALITY_WORKSPACE.md)：筛选分页、解析覆盖可信度、历史快照比较及范围说明 |

智能问答必须由用户配置生成模型后使用；本地规则引擎只生成报告，不是免费的默认问答模型。本地嵌入模型负责检索，也不能替代生成模型。真实模型回答正确性不能用离线检索通过率或合法引用数量代替。

## 验证与发布资料

- [本轮推送前检查](./PRE_PUSH_CHECK.md)：类型绑定修正、验证环境隔离、文件整理与本轮验收边界。
- 常规检查：[验证脚本](../scripts/verify_project.ps1) 和 [CI 定义](../.github/workflows/ci.yml)。交付顺序及显式评测命令见 [DELIVERY.md](./DELIVERY.md)。
- 常规 CI 的证据评测使用仓库内合成样例，不自动下载真实语料或模型，不调用真实生成模型；依赖安装和 Playwright 浏览器安装仍需要网络，不能称整个 CI 完全离线。
- 真实语料必须先由用户显式准备本地 corpus；耦合评测只校验已有语料，问答语义组还需提供已有本地模型目录。没有准备完成时不能冒充已经测过。
- 历史版本说明：[v0.8.0](./releases/v0.8.0.md)、[v0.8.1](./releases/v0.8.1.md)、[v0.9.0](./releases/v0.9.0.md)。普通代码推送不等于发布新 Release；推送 `v*` 标签会触发 [Release 工作流](../.github/workflows/release.yml)。
- 截图：[assets/](./assets/)。旧截图用于演示参考，发布前复核是否仍符合当前界面并完成脱敏。

## 信息来源原则

- 功能状态以当前代码与有日期、执行范围的测试记录为准；历史验收文档不覆盖改写。
- 性能、检索、静态关系探针和自动化测试是不同口径，不能相互证明或合并计算。
- 不提交 API Key、日常 SQLite 数据库、导入的第三方源码或含私有内容的运行报告；经过审查的固定标注与可公开复核的评测摘要保留在既有目录。
- 简历只使用已经测量且注明样本范围的数据，不使用计划值、占位数字或“零误报”“全面准确”等未验证结论。
