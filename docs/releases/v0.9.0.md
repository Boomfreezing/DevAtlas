# DevAtlas v0.9.0

`v0.9.0` 将代码搜索从“查看片段”升级为可直接阅读上下文的源码查看流程。

## 新增功能

- 搜索结果新增“查看代码”，无需离开当前页面即可打开完整源码。
- 查看器展示文件路径、语言、大小、总行数和行号。
- 自动滚动到首个命中行，并高亮命中范围与查询关键词。
- 支持复制文件路径、复制完整代码、按 `Esc` 或按钮关闭。
- 桌面端与窄屏布局均可使用。

## 后端与安全

- 新增 `GET /api/projects/{project_id}/files/{file_id}/content`。
- 同时验证项目与文件归属，并确保解析路径位于仓库根目录内。
- 拒绝二进制文件和超过 2 MB 的文件。
- 源码接口只读，不执行代码，也不会自动调用外部模型。

## 验证

- 后端 API 测试覆盖正常读取、错误文件 ID、二进制文件、超大文件和磁盘文件丢失。
- Vitest 覆盖查看器打开、内容渲染、高亮、复制路径和关闭。
- Playwright 覆盖“搜索 → 加载更多 → 查看源码 → 命中定位 → 关闭”的真实主流程。
- 31 项后端测试通过，总覆盖率 85.70%；8 项前端测试与生产构建通过；1 条 Playwright 主流程通过。
