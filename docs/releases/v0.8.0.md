# DevAtlas v0.8.0

DevAtlas 的首个简历展示预发布版本。该版本提供一条完整的本地代码仓库分析链路：安全导入仓库、解析代码结构、搜索代码、检查依赖与质量，并生成可预览和导出的 Markdown 分析报告。

## 核心功能

- 支持 ZIP、本地文件夹和公开 GitHub 仓库 URL 导入。
- 通过后台任务展示仓库接入、扫描、解析和索引阶段进度。
- 使用 Tree-sitter 解析 Python、TypeScript 和 JavaScript 的函数、类、接口、方法及导入关系。
- 使用 BM25 提供包含文件路径、行号、代码片段和相关性得分的项目内搜索。
- 提供交互式依赖图谱、节点出入度信息和循环依赖检测。
- 提供 6 条确定性代码质量规则、百分制评分和针对性修复建议。
- 默认使用免费的本地规则引擎生成报告，可选接入 Ollama 或 OpenAI Responses API。
- 支持报告预览、重新生成和 Markdown 文件导出。
- 使用文件元数据和 SHA-256 实现新增、修改、删除文件的增量分析。

## 工程化与验证

- React 19 + TypeScript + Vite 前端。
- FastAPI + SQLAlchemy + SQLite 后端。
- Docker Compose 一键启动。
- GitHub Actions 自动执行后端、前端和 Playwright e2e 检查。
- 29 项后端测试通过，覆盖率 85.54%。
- 7 项前端测试和 1 项核心用户路径端到端测试通过。
- 中型样本仓库无变化增量分析中位数为 10.90 ms，较全量分析最高加速 15.41×。

## 当前限制

- 结构解析当前覆盖 Python、TypeScript 和 JavaScript。
- GitHub URL 导入当前只支持公开仓库。
- OpenAI Responses 入口不直接兼容 DeepSeek、Claude 等供应商的原生协议。
- 本地向量搜索和混合检索尚未实现。
